# Face-detection-opencv

A real-time attendance management system built using Python and OpenCV.  
This project detects faces through webcam input and detect mood by lenghth of youe eye opened
## Features
- Real-time face detection
- Webcam integration
-Mood detector via eye     

## Technologies Used
- Python
- OpenCV
- Pandas
- NumPy

## Project Structure
attendance-system/
│── Smart_face_detection.py
│── haarcascade_frontalface_default.xml
│── README.md

## How to Run
1. Install dependencies:
pip install opencv-python pandas numpy

2. Run the project:
python main.py
